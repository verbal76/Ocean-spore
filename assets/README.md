# Assets

Drop game art, sounds, and other media files here.

Suggested subfolders:
- `sprites/` — boat, enemy, pickup images (PNG, with transparency)
- `audio/` — sound effects and music (MP3/OGG)
- `ui/` — HUD icons, fonts, etc.

When you add a file, tell me the path and what it is and I'll wire it into the game.
