# Asset provenance

What ships in the APK, where it came from, and its licence status. Keep this
current when assets change (CI pins the bundled GLBs and colormap by SHA-256 in
`bundled-assets.sha256`).

| Asset | Origin | Licence status |
|---|---|---|
| `*.glb` (15 bundled: 7 player ships, 7 enemies, boss) and `colormap.png` | Recovered byte-for-byte from the original `build-39` APK / source `a3f17b6`. File names and the shared colormap follow the Kenney "Watercraft Kit" convention (`boat-*`, `ship-*`, `colormap.png`) | **Not verified from the repository** (no licence file was ever committed). Kenney kits are normally CC0, but this must be confirmed against the original download before any public release |
| The other ~60 `*.glb` and the two `*CodezlyBasicTexturePack1*` PNGs | Present in the tree, never bundled in any APK (unreferenced) | Same caveat; remove or document before any public release |
| `branding/hot-attic-logo.png` | Scale-only derivative of the canonical `Hot_Attic_Games_Master_Logo_ALPHA_FINAL.png` (SHA-256 `e3d9bb56...48c4e`); verified by `scripts/check-brand.py` | Hot Attic Games artwork |
| `icons/*` | Original, generated by `scripts/make-icons.py` | Original |
| `audio/*.wav` | Original, synthesized by `scripts/make-audio.py` | Original, nothing to attribute |

## Rules
- Do not add third-party audio, art or fonts without recording the source and
  licence here first.
- Public distribution requires resolving the "not verified" rows above.
