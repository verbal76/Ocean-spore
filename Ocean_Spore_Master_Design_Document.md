# Ocean Spore
## Master Naval Survival Game Design Document

# Project Status

The repository Ocean Spore is already prepared with:
- ship GLB files
- blaster weapon assets
- water tiles
- sand tiles
- island assets
- harbor ramp assets

The repository is considered prototype-ready for expansion.

# High Concept

Ocean Spore is a stylized arcade naval survival sandbox focused on:
- exploration
- ship progression
- momentum
- naval combat
- replayability
- build crafting
- addictive gameplay loops
- discovery

The player begins with a weak small vessel and gradually evolves into a terrifying ocean war machine.

The emotional fantasy is:
"I started with a tiny junk ship and became a floating apocalypse fortress."

# Harbor and Shipyard System

Harbors replace the garage system from Zombie Vehicle Survival.

Players physically discover:
- islands
- harbors
- docking stations
- ramps

When the player approaches:
- harbor ramps
- docking zones
- island docks

the ship should auto dock.

Once docked:
the Shipyard interface opens automatically.

# Shipyard Features

Shipyards offer:
- repairs
- buffs
- upgrades
- new weapons
- ship unlocks
- build customization

Shipyards should feel:
- rewarding
- safe
- exciting

# Currency System

The primary currency is:
Parts

Parts are earned through:
- kills
- enemy destruction
- salvage
- exploration
- boss kills

Parts are used for:

- buffs
- weapons

# Ship Unlock System

Ships unlock through mastery progression.

Example:

Unlocks:

The player should FEEL they earned the next vessel.
